Claude u Windows trayu

Simulacija statusne ikone za Claude Code u traci Windowsa 11, samo s onim što službeni API dopušta: ikona koja se animira, tooltip i izbornik sesija. Na 100 % zooma preglednika traka i ikona su u stvarnoj veličini.

Ikona izbliza

Svako stanje u 16 × 16 piksela, koliko Windows daje tray ikoni na 100 % skaliranja. Ovdje je uvećano šest puta da se vidi svaki piksel. Ispod svakog stanja piše koji ga Claude Code hook postavlja.

Pored ikone može stajati tekst bilo koje širine, pa su radnja i timer uvijek vidljivi.

Windows tray

Stoji samo ikona. Radnju i timer vidiš u tooltipu kad prijeđeš mišem preko ikone.

Ovo je službeni Win32 API

  • Ikona i animacija: Shell_NotifyIcon, sličice se izmjenjuju s NIM_MODIFY
  • Tooltip do 127 znakova (szTip), osvježava se uživo
  • Izbornik na klik i prebacivanje na prozor sesije

Ovo ne ide bez hacka

  • Tekst koji stalno stoji pored ikone
  • Programski prebaciti ikonu iza ^ na traku

Sesije, projekti i upiti u simulaciji su primjeri.
